| 75 | A call dropping or adding an argument that restates its parameter's literal default is a new kind, `default_argument`, ranked between `restyle` and `rename`. The callee takes no rest (`*args`, `**opts`, `**nil`, `...`) and doesn't read its frame; the dropped value and the default are the same plain literal (number, symbol, uninterpolated string, `nil`, `true`, `false`, empty `{}`/`[]`) by `Node::canon`, with the same magic comments in every file involved.
